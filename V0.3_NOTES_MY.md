# Mandalay Smart Map V0.3 — Android testing notes

## Changes implemented
- Compact blue/white Android screen, smaller buttons and cards, search + map + results.
- Offline / Online OSM modes with an explicit source label.
- Offline token matching: "jocole mobile shop" searches useful name words instead of a single exact phrase, when that shop exists in the local data.
- User-triggered OpenStreetMap Nominatim online search, up to 15 matches near Mandalay, with offline save for permitted OSM data.
- Search results have compact cards and quick ☆ Save buttons.
- Sync progress 0–100% based on 8 processed steps (4 road sections + 4 places sections). This is **NOT percentage of downloaded bytes** or proof that Mandalay data is complete.
- Map and result list refresh between downloaded sections. Partial successes are retained in SQLite.
- App versionName 0.3.0 / versionCode 3.
- Existing GPS fix from 0.2 remains.

## Important limitations
1. OpenStreetMap, Nominatim and the four-tile pilot area do **not** cover every shop in Mandalay.
2. This is **not** ChatGPT's multi-source live search. There is no in-app Google Places/Facebook/TikTok business collection. The 🌐 Web button opens a browser search only; results from that browser are **not automatically imported**.
3. Public Nominatim is only suitable for a small, manually-triggered personal pilot; for real public app traffic an owned/licensed search service and caching backend are required. Follow OSM attribution and ODbL.
4. Initial road and place download requires Internet, and can partially fail due to Overpass outages. Offline data is usable once downloaded or manually saved.
5. Source files were updated on GitHub but this revision **has not been rebuilt and tested on a phone yet**. Run a new Codemagic build of the latest `main` branch.

## Build from Android phone only
1. Open https://codemagic.io and select Mandalay-Shop-Map.
2. Choose Start new build (not retry an old build), branch `main`, workflow `android-debug`.
3. Wait for successful build; open Artifacts and download `app-debug.apk`.
4. The new debug APK may have a different signing key. If upgrading fails, first backup locally saved app data. Uninstalling wipes its local SQLite database.
5. Launch and check Offline/Online, Sync progress, Saved places, and GPS.
